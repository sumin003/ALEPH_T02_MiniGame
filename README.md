# 🌟 Lost Stars

우주를 배경으로 잃어버린 별을 구출하는 미니게임입니다.  
플레이어는 우주선을 좌우로 조작하여 떨어지는 별을 구출합니다.

## 🎮 게임 방법

1. 게임을 시작합니다.
2. 좌우 방향키를 사용하여 우주선을 움직입니다.
3. 떨어지는 별을 구출합니다.
4. 정해진 조건을 달성하면 성공합니다.
5. 실패하거나 게임이 끝나면 다시 시작할 수 있습니다.

## ⌨️ 조작 방법

| 키 | 기능 |
| --- | --- |
| ← | 왼쪽으로 이동 |
| → | 오른쪽으로 이동 |
